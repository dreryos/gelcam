## Next steps (in order)

### 1. Pipeline – finish stage 2 (`src/gelcam/processing/`)

Pure functions, numpy in/out, `float32` only, one test per step (plan ch. 6, rules in ch. 8).

- [ ] `calib.py` – master dark (median of N darks), master flat `F̂ = (F − D_F) / mean(F − D_F)`.
- [ ] `align.py` – phase correlation, resample only when shift > 0.5 px (try numpy FFT to drop OpenCV).
- [ ] `stack.py` – iterative 3σ clipping + mean; channels in `numpy.memmap`, stacking in tiles
      (never all frames in RAM; target peak < ~500 MB).
- [ ] `binning.py` – 2×2 optional.
- [ ] `export.py` – `result.tif` 16-bit linear, `preview.png`, `metadata.json` with every step
      (plan ch. 7); `tifffile` imported lazily.
- [ ] `pipeline.py` + CLI over stored RAW (`uv run python -m gelcam.processing …`).
- [ ] Tests on synthetic gel (`testing/synthetic.py`): noise ≈ 1/√N, linearity of band ratios,
      hot pixels gone after dark, vignetting gone after flat; saturation mask from per-frame
      `white_level` (ISO dependent).
- [ ] Check on real sets: UV scene 16× 4 s with darks 4 s (same sensor state), flat 8 s.

**Done when:** synthetic test confirms SNR gain ≈ √N and linearity; real scene processes
within the memory limit (`tools/bench.py`).
