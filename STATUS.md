## Prototype (10 Nov 2026) — what is left out

Built over MockCamera, verified offscreen only (not yet on Windows with the 100D):
- Live view: no navigator thumbnail, no "AF point: click in the image", no sharpness sparkline
  or auto fine-focus, no "Detected applications" panel in LV3 (blockers are EDSDK-side).
- Wizard: no flat library (flat recorded as skipped), no SNR/drift stats, thumbnails are
  numbered squares; it never writes `result.tif` — status in metadata is
  "captured; processing pending" until the pipeline exists.
- Mock quirk: at 10× the mock's live view is a blocky upscale, so sharpness is noise-dominated
  and the AF-failed note can show with the mock.
- No `.ts`/`.qm` translations generated yet (strings are all in `tr()`).

## Next steps (in order)

### 1. Pipeline – stage 2 — done (10 Nov)

- [x] calib (sigma-clipped mean master dark/flat), framestack (memmap), stack (robust sigma
      clip), align (numpy phase correlation), binning, export, pipeline, CLI, wizard "Process".
- [x] Synthetic checks: noise ≈ 1/√N, band ratios within 3 %, hot pixels, vignetting, shifts.
- [x] Real UV scene: noise ratio 0.464 with 8 darks (theory 0.469), 7.6 s, 530 MB peak RSS.
- [ ] Decide: 2 × N darks by default (ratio ~0.41 instead of 0.46, twice the dark time)?
- [ ] Take a UV flat (uniformly fluorescing plate) — the white-light flat does not describe UV
      illumination (see plan ch. 10 "Flat field findings").
